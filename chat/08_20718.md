3. 세 가지 분석 방법의 차이
분석 방법

특징

다중 선형회귀

여러 타격 지표와 예측 대상 사이의 선형 관계 분석

랜덤 포레스트

여러 의사결정트리를 결합하여 예측

XGBoost

이전 모델의 오차를 보완하며 순차적으로 학습

분석 결과 해석 방법

R²: 1에 가까울수록 예측 성능이 좋은 편이야.

MAE: 실제값과 예측값의 평균적인 차이야. 낮을수록 좋아.

RMSE: 예측 오차를 제곱해 계산하므로 큰 오차에 더 민감해. 낮을수록 좋아.

변수 중요도: 랜덤 포레스트와 XGBoost가 예측에 활용한 변수의 상대적 중요도를 보여줘.

참고로 R²가 높다고 해서 변수 사이에 인과관계가 있다는 뜻은 아니야. 또한 변수 중요도 역시 원인이나 영향력을 직접 증명하지는 않아.
